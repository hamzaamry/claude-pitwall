What changed between runs

B1 → B2 +$0.60

  • Hooks force main to send searches to scouts and tests to the runner, and to get its plan approved.
  • Helpers ran in the background: 12 extra "waiting on…" turns, each one re-reading ~90k tokens.
  • 3 separate Opus reviewers: $0.56.

B2 → B3 −$0.51

  • Helpers run in the foreground: waiting turns 12 → 0, main turns 34 → 22.
  • One reviewer per session, continued with SendMessage so it reuses its cached context: $0.56 → $0.24.
  • One final review per task; the reviewer searches through scouts too.

Caveats

  • One run per setup, on one task. Not enough yet for a README claim.
  • B1 is still the cheapest run ($0.98), but there main did nearly everything itself, on Sonnet. B3 costs 9 cents more, and in exchange the plan and the diff get an Opus check.
  • Main is now 76% of the cost: every turn re-reads ~50–110k tokens of context. Cutting that fixed context is the next big saving.
  • No Sonnet-alone run (C1) yet, so the "cheaper model" effect and the "team" effect are not separated.
